## Focus Areas

- Single Pane of Glass executive dashboards
- Data standards digitization and configuration management
- AI-ready standards assessment
- Local-first AI assistants and RAG workflows
- Dockerized web application prototypes
- GitHub Actions and lightweight CI/CD pipelines
- SharePoint-ready and self-hosted dashboard concepts

## Featured Project Themes

### Enterprise Single Pane of Glass
Leadership-oriented dashboards for decision visibility, action tracking, risk awareness, readiness views, data product registry concepts, and operational status monitoring.

### Digital Configuration Management
Tools and prototypes for standards libraries, structured document conversion, NISO STS-style modeling, artifacts, ICPs, IEPDs, and lifecycle workflow tracking.

### Local-First AI Applications
Offline-capable and self-hosted AI assistants using Docker, local storage, Ollama-compatible models, and browser-first workflows.

### Prototype Pipeline Template
Reusable Docker Desktop, GitHub Actions, and GitHub Container Registry starter kit for rapidly packaging and releasing prototype web applications.
